## How this repository works

1. Each sprint has its own folder. Read `LEARN.md`, write your own notes in `notes/`, and put the work for each task in `tasks/`.
2. Work on a **branch** named after the sprint, for example `sprint-1`, and open a **pull request** when you are ready. Your mentor reviews it.
3. Answer `ASSESSMENT.md` in your own words in the same pull request.
4. The team's project lives in `final-project/`.
